# 03 — VIDEO EDITOR

Рабочее пространство для монтажа видео из хранилища FLOUSTREAM или галереи телефона. Добавь до 10 вариантов обложки видеоредактора.

Загружай варианты с именами `01.jpg` … `10.jpg` (или `.webp`). Лучше вертикальный формат 9:16, 1080×1920 или выше. Рекомендуемый размер файла — до 15 МБ.
