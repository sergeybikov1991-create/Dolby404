# AuTHOR — Banner image library

Эта папка предназначена только для подбора и согласования изображений четырёх полноэкранных баннеров AuTHOR. Сайт и APK здесь не изменяются.

## Как загружать

- Открой нужную подпапку.
- Нажми **Add file → Upload files**.
- Загрузи до 10 вариантов в каждую категорию.
- Имена файлов: `01.jpg`, `02.jpg` … `10.jpg` (или `.webp`).
- Не заменяй уже загруженные варианты без согласования.

Рекомендуется: JPG или WebP, вертикальная композиция 9:16, желательно 1080×1920 или выше (например, 2160×3840), размер одного файла до 15 МБ для удобства.

## Категории

1. `01-my-videos` — обложка видеотеки автора.
2. `02-my-photos` — обложка фотогалереи автора.
3. `03-video-editor` — видеоредактор.
4. `04-shorts` — редактор Shorts.

После загрузки напиши, какие номера тебе нравятся. До выбора изображения не подключаются к сайту.
