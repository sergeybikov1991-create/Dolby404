# FLOUSTREAM VOICE — план реализации

## Исходная точка

- Базовая ветка: `release/floustream-0.4.28`.
- Базовая версия приложения: `0.4.28`, versionCode `36`.
- Пакет Android: `com.dolby404.messenger`.
- UI: Kotlin + Jetpack Compose.
- У приложения уже есть запись голосовых сообщений. FLOUSTREAM VOICE — отдельная функция управления и диалога; существующую запись голосовых сообщений не переписывать.
- Не изменять зафиксированные рабочие функции: кэш чатов, F-кнопку/веер вложений, импорт и отображение фото/видео из галереи.

## Продуктовое решение

Два способа активации:
1. Кнопка микрофона (нажал — говоришь — отпустил/остановил).
2. Фраза пробуждения «Привет, Флоу».

Помощник — полноценный голосовой собеседник: распознаёт русскую речь, отвечает голосом, понимает контекст текущей задачи и выполняет разрешённые действия внутри приложения.

## Ограничение стоимости

Приоритет пользователя: максимально передовые бесплатные решения. Не добавлять обязательные платные API, подписки или облачные голосовые сессии. Начальная версия должна работать локально и без оплаты за запросы. Не встраивать в APK секретные ключи.

## Архитектура

Разделить систему на независимые слои:

- **Voice UI** — кнопка/состояния прослушивания, распознавания, ответа и выполнения команды.
- **Speech-to-Text** — sherpa-onnx как основной кандидат для локального распознавания речи; выбрать и проверить русскую модель, размер и скорость на OnePlus 10T (ARM64) до включения в APK.
- **Dialogue** — локальная открытая языковая модель через совместимый Android runtime. До выбора конкретной модели провести сравнительный тест качества русского языка, памяти, скорости первого токена, скорости генерации, размера файлов и лицензии. Не обещать полноценный уровень облачных моделей на мобильном устройстве.
- **Command Router** — белый список команд и проверка контекста; модель возвращает структурированное намерение, но не вызывает произвольные Android API, shell-команды или SQL.
- **Text-to-Speech** — сначала проверить встроенный Android TextToSpeech и доступность русского голоса офлайн. Если качество/доступность недостаточны, исследовать совместимую локальную модель TTS на базе sherpa-onnx.
- **Wake Word** — отдельный этап после устойчивого push-to-talk; исследовать локальное обнаружение фразы «Привет, Флоу». Для фонового прослушивания требуется явно включаемый пользователем foreground service с постоянным уведомлением и видимым индикатором микрофона; скрытое прослушивание запрещено.

## Этапы

### Этап 1 — бесплатный локальный голосовой диалог по кнопке
- Добавить отдельную точку входа FLOUSTREAM VOICE, не меняя существующий жест записи голосового сообщения.
- Запросить разрешение на микрофон в момент первого использования.
- Реализовать локальное распознавание русской речи.
- Показывать распознанный текст и ответ помощника.
- Озвучивать ответы локальным TTS.
- Сначала поддержать диалог и безопасные команды навигации: открыть чаты, открыть список контактов, показать медиа.
- Отправку сообщения, удаление, изменение настроек и запуск звонка выполнять только после явного подтверждения пользователя.
- Не запускать запись одновременно с записью голосового сообщения, камерой или звонком.

### Этап 2 — локальная языковая модель и команды приложения
- Сравнить несколько актуальных открытых моделей, которые реально помещаются в доступную память OnePlus 10T; проверить лицензии и коммерческие ограничения.
- Контакты и чаты: поиск, открытие, переход к переписке.
- Диктовка в поле сообщения с сохранением черновика.
- Отправка только после отдельной команды/подтверждения.
- Звонки — только после подтверждения контакта и типа звонка.
- При нехватке ресурсов использовать ограниченный локальный командный режим, а не скрыто обращаться к платному сервису.

### Этап 3 — фраза пробуждения
- Реализовать только после успешной проверки этапов 1–2.
- Явное включение/выключение в настройках.
- Запуск и остановка пользователем; видимое постоянное уведомление во время работы микрофона.
- Учитывать ограничения Android на фоновые службы микрофона и жизненный цикл приложения.

## Критерии проверки

- Русская речь распознаётся на OnePlus 10T / Android 15.
- Базовый голосовой сценарий работает без интернета и без платных API.
- Размер моделей и расход RAM/CPU/батареи измерены на целевом телефоне.
- Кнопка голосового диалога не ломает запись голосовых сообщений.
- При отказе в разрешении микрофона приложение остаётся работоспособным.
- Нет скрытого фонового захвата звука.
- Команды отправки/удаления/звонка не исполняются без подтверждения.
- Существующие чат-кэш, веер вложений и работа фото/видео остаются без изменений.
- Сборка и установка проходят через существующий GitHub Actions / механизм обновления FLOUSTREAM; не требовать ручной установки APK для пользовательской проверки.

## Принципы выбора технологий

- Предпочитать проекты с открытым исходным кодом, проверяемой лицензией и активной поддержкой Android/ARM64.
- Проверять первоисточник, лицензию каждой модели и runtime отдельно: открытый код движка не означает автоматически свободную лицензию на все веса моделей.
- Не выбирать модель только по размеру или рейтингу; обязательно тестировать русский язык и производительность на OnePlus 10T.
- Платные облачные модели не входят в обязательную архитектуру. Возможность подключить их позднее может быть только необязательным модулем с отдельным согласием пользователя.
