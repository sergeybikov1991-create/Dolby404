# Эталон: боковая навигационная панель FLOUSTREAM для APK 2.0

Статус: ЗАФИКСИРОВАНО по прямому подтверждению пользователя от 20.11.2026.

## Исходная рабочая реализация
- Ветка: `APK-2.0`
- Эталонный коммит реализации: `684f15b759e2fcdf22597e93ccf2d312ed6d3ff7`
- Файл: `android-web-shell-test/app/src/main/assets/index.html`
- Сборка проверки: GitHub Actions run #10, run ID `44669442742`
- Artifact: `FLOUSTREAM-WebShell-Test-debug`

## Зафиксированное поведение
- Кнопка открывает боковую панель с анимированным индикатором.
- Панель выдвигается слева; фон страницы затемняется.
- Закрытие доступно крестиком, нажатием по затемнённой области и клавишей Escape.
- Поддерживается открытие свайпом от левого края и закрытие свайпом влево.
- Внутри пока оставлен только логотип FLOUSTREAM: пункты меню намеренно не добавлены.

## Правила сохранения
- Использовать эту реализацию как неизменяемую точку отсчёта для дальнейшей разработки навигации в APK 2.0.
- Не удалять и не переписывать зафиксированное поведение без отдельного разрешения пользователя.
- Новые пункты меню и содержимое добавлять поверх эталона, не ломая открытие, закрытие, затемнение и жесты.
- Ветка сайта остаётся источником-эталоном для изучения; изменения этой записи и APK вносить только в ветку APK 2.0.
- Это эталон APK 2.0 WebView-модуля, не основного Android Messenger APK.
