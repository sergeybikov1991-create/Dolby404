# Эталон APK 2.0 — Оповещения Firebase (FCM)

Статус: **проверено пользователем на устройстве; рабочая контрольная точка**.

## Что сохранено

Эта ветка является отдельным эталонным снимком разработки push-уведомлений для FLOUSTREAM APK 2.0. В ней сохранён полный исходный код APK 2.0 с интеграцией Firebase Cloud Messaging, включая:

- Firebase Android-конфигурацию для пакета `com.floustream.webshelltest`;
- зависимости и настройки Gradle для Firebase;
- объявление сервиса и разрешений в Android Manifest;
- `FLOUSTREAMMessagingService.kt` для приёма FCM-сообщений и показа Android-уведомлений;
- `PushTokenRegistrar.kt` для регистрации FCM-токена устройства в Supabase;
- изменения `MainActivity.kt` для запуска регистрации токена и обработки перехода из уведомления;
- workflow сборки APK 2.0 с FCM.

## Важные границы

- Исходный эталон APK 2.0 не изменять.
- Сайт FLOUSTREAM не изменялся в рамках этой разработки.
- Supabase schema/functions не изменялись в рамках этой Android-работы; серверная функция отправки FCM использует уже существующую инфраструктуру.
- Не коммитить приватный Firebase Service Account key или секреты Supabase. Файл `google-services.json` — клиентская конфигурация Android-приложения, не приватный service-account key.
- Все следующие доработки выполнять в новых рабочих ветках, создаваемых от этого эталонного снимка или от явно выбранной более новой рабочей версии. Не вносить новые изменения непосредственно в эту reference-ветку.
